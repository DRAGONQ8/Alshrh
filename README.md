# نَحْو ببساطة

[افتح الموقع](https://nahw-simple-q8.qq8081927.chatgpt.site) — النسخة المستضافة على Sites خاصة بحساب المالك.

موقع عربي بسيط لتعلّم **الفعل والفاعل والمفعول به** من خلال شرح قصير و**٨ أسئلة سهلة فقط**.

- واجهة فاتحة، ونص واضح، وتصميم مناسب للجوال.
- سؤال واحد في كل مرة، وثلاثة اختيارات، وتلميح اختياري.
- تستطيع تغيير اختيارك قبل «تحقّق من إجابتي»، ثم تقرأ تفسيرًا قصيرًا وتكمل للسؤال التالي.
- حفظ التقدّم في المتصفح عند إتاحة التخزين، ومراجعة الإجابات، وبدء جولة جديدة بعد التأكيد.
- جميع الخطوط والتنسيقات والبرمجة مضمّنة؛ يمكن تنزيل ملف HTML وفتحه دون إنترنت.

افتح `nahw-interactive.html` في المتصفح. ملف `index.html` مطابق له ومخصّص لفتح الموقع مباشرة عند استضافته على GitHub Pages.

## التحقّق أثناء التطوير

اختبارات منطق الإجابات، دون حزم إضافية:

```sh
node --test tests/core.test.cjs
```

اختبارات المتصفح تحتاج Python Playwright وChromium. شغّل خادمًا محليًا من مجلد المشروع:

```sh
python -m http.server 8765
```

وفي نافذة أخرى:

```sh
NAHW_URL=http://127.0.0.1:8765/nahw-interactive.html python tests/browser_smoke.py
```

يمكن تخصيص مسار Chromium بمتحوّل `CHROMIUM_PATH`. تشمل الاختبارات إكمال الأسئلة الثمانية، والتقييم، وتصحيح الاختيار، والتلميح، والحفظ والتخزين المعطّل، وإعادة التدريب، وتصدير HTML، وإمكانية القراءة، وعدم تمدّد الصفحة على الكمبيوتر والجوال.
