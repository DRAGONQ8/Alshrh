# نَحْو — كل جملة لها حكاية

موقع عربي تفاعلي لتعلّم الفعل والفاعل والمفعول به، داخل ملف HTML واحد مع الخطوط والتنسيقات والبرمجة مضمّنة.

افتح `nahw-interactive.html` في المتصفح. يعمل دون تثبيت أو اتصال بالإنترنت، ويمكن تنزيل نسخة منه من إعدادات الموقع.

- عشرة أسئلة ضمن خمس مراحل؛ كل مرحلة سؤالان مترابطان.
- تدريب فردي ونقاش جماعي، وتلميحات وشرح تدريجي وتفسير للاختيار الخاطئ.
- يمكن تعديل الاختيار قبل «تحقّق من إجابتي». عرض الشرح دون تقييم لا يمنح نقطة.
- حفظ التقدّم في المتصفح عند إتاحة التخزين، مع مراجعة كل سؤال وإعادة تدريب الأسئلة التي تحتاج مراجعة.
- أمثلة دروس قابلة للاستكشاف، ودعم لوحة المفاتيح وتقليل الحركة وتكبير العرض.

## التحقّق أثناء التطوير

اختبارات منطق الإجابات، دون حزم إضافية:

```sh
node --test tests/core.test.cjs
```

اختبارات المتصفح تحتاج Python Playwright وChromium. من مجلد المشروع، شغّل خادمًا محليًا:

```sh
python -m http.server 8765
```

وفي نافذة أخرى:

```sh
NAHW_URL=http://127.0.0.1:8765/nahw-interactive.html python tests/browser_smoke.py
```

تغطي الاختبارات التقييم والتصحيح وترتيب الكلمات والمراجعة والحفظ والتخزين المعطّل وتصدير HTML ومقاسات الجوال والتابلت. يمكن تخصيص مسار Chromium بمتحوّل `CHROMIUM_PATH`.
